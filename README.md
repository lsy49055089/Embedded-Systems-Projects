# On-Device Embedded Projects

STM32와 ARM Cortex-M 기반 임베디드 시스템 프로젝트를 정리한 포트폴리오 저장소입니다.

## Projects

| 프로젝트 | 핵심 내용 | 주요 기술 |
|---|---|---|
| [STM32 Cortex-M4 LED Mini Games](./cortex-m4-led-games) | 반응속도 게임과 LED 기억력 게임을 하나의 메뉴 시스템으로 구현 | STM32 NUCLEO-F411RE, C, GPIO, Timer, UART, I2C LCD, Buzzer |

각 프로젝트 폴더에는 소스 코드, 빌드 구성, 하드웨어 기능과 실행 방법을 정리했습니다.
