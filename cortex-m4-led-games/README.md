# STM32 Cortex-M4 LED Games

STM32에서 반응시간과 버튼 입력 순서를 판정하고, 결과를 LED·LCD·부저·UART로 전달하는 두 가지 게임을 구현했습니다.

## 담당 역할

- 타이머 기반 반응시간 측정과 선입력·동시 입력·버튼 해제 처리
- GPIO·LCD·부저·UART 출력 및 빌드·다운로드 구성


## 설계·구현

### 구현 요약

| 구분 | 핵심 내용 |
|---|---|
| 반응속도 게임 | 10라운드 구성, 제한시간 약 1,000→550 ms, 입력 시간 판정 |
| 기억력 게임 | LCD의 L·M·R 수열 생성·표시와 입력 순서 비교 · 최대 16단계 |
| 입력 처리 | 선입력·동시 입력·시간 초과 구분, 버튼 해제 대기로 반복 입력 방지 |
| 주변장치 연동 | GPIO, 타이머, LCD, 부저, 115200 bps UART |
| 상태 확인 | LCD와 UART에 라운드·성공·실패 원인 표시 |

반응시간과 입력 순서를 기준으로 게임을 판정하고, 결과를 여러 출력 장치로 전달하는 구조입니다. 아래에는 조작 방법, 빌드·다운로드 절차와 문제 해결 방법을 정리했습니다.

<a id="11-프로그램-동작-구조"></a>

### 프로그램 동작 구조

프로그램은 다음과 같은 순서로 동작합니다.

```text
시스템 초기화
    ↓
LED, 버튼, UART, LCD, 부저 초기화
    ↓
게임 선택 메뉴 출력
    ↓
사용자 버튼 입력
    ↓
반응속도 게임 또는 기억력 게임 실행
    ↓
게임 결과 출력
    ↓
반응속도 종료·기억력 16단계 완료 후 RESET으로 메뉴 복귀
기억력 오답 후 USER로 1단계 재시작
```

<a id="12-주요-소프트웨어-기능"></a>

### 입력·출력 제어

#### 12.1 버튼 입력 처리

버튼 입력은 다음 상태를 구분하여 처리합니다.

* 아무 버튼도 누르지 않은 상태
* 버튼 1개가 눌린 상태
* 여러 버튼이 동시에 눌린 상태
* 버튼이 눌렸다가 해제된 상태

버튼을 계속 누르고 있을 때 하나의 입력이 여러 번 처리되지 않도록 버튼이 모두 해제될 때까지 기다리는 기능을 사용합니다.

#### 12.2 LED 제어

LED 제어 기능은 다음과 같습니다.

* LED 전체 끄기
* 특정 LED 켜기
* 반응속도 게임의 목표 LED 출력
* 게임 종료 시 LED 초기화

#### 12.3 타이머 사용

타이머는 다음 기능에 사용됩니다.

* 반응속도 제한시간 측정
* 무작위 대기시간 처리
* LED 점등시간 제어
* 반응속도 게임의 입력 제한시간 처리
* 부저 음 길이 조절

#### 12.4 난수 사용

반응속도 게임에서는 켜질 LED와 대기시간을 예측하기 어렵게 하기 위해 난수를 사용합니다.

기억력 게임에서는 L·M·R 수열을 생성하고, 정답일 때 기존 수열 뒤에 한 항목을 추가합니다.

<a id="3-프로젝트-주요-기능"></a>

### 게임 선택

#### 3.1 게임 선택 메뉴

프로그램이 시작되면 LCD와 UART 터미널에 게임 선택 메뉴가 표시됩니다.

```text
SELECT GAME
<REACT  MEMORY>
```

버튼 기능은 다음과 같습니다.

| 버튼   | 메뉴 기능      |
| ---- | ---------- |
| BTN1 | 반응속도 게임 선택 |
| BTN3 | 기억력 게임 선택  |

게임 선택 후 USER 버튼을 누르면 해당 게임이 시작됩니다.

<a id="4-반응속도-게임"></a>

### 반응속도 게임

#### 4.1 게임 설명

반응속도 게임은 무작위로 켜지는 LED를 확인한 후, 해당 LED에 대응하는 버튼을 제한시간 안에 누르는 게임입니다.

총 10라운드로 구성되며 라운드가 진행될수록 제한시간이 짧아집니다.

#### 4.2 LED와 버튼 대응 관계

| 켜진 LED | 눌러야 하는 버튼 |
| ------ | --------- |
| LED1   | BTN3      |
| LED2   | BTN2      |
| LED3   | BTN1      |

UART 터미널에는 다음과 같이 표시됩니다.

```text
LED REACTION GAME - 10 ROUND
BTN1 -> LED3
BTN2 -> LED2
BTN3 -> LED1
```

#### 4.3 게임 진행 순서

1. 게임 시작 음악이 재생됩니다.
2. LCD와 UART에 현재 라운드가 표시됩니다.
3. 무작위 대기시간 동안 버튼을 누르지 않고 기다립니다.
4. LED 1개가 무작위로 켜집니다.
5. 켜진 LED에 대응하는 버튼을 누릅니다.
6. 제한시간 안에 올바른 버튼을 누르면 다음 라운드로 진행합니다.
7. 잘못된 버튼을 누르거나 제한시간을 초과하면 게임이 종료됩니다.
8. 10라운드를 모두 성공하면 게임 클리어 화면이 표시됩니다.

#### 4.4 제한시간

반응속도 게임은 다음과 같이 진행될수록 제한시간이 감소합니다.

```text
1라운드 제한시간 : 약 1000ms
마지막 라운드 제한시간 : 약 550ms
```

따라서 뒤쪽 라운드로 갈수록 빠른 반응이 필요합니다.

#### 4.5 실패 조건

다음 조건 중 하나가 발생하면 게임 오버가 됩니다.

* LED가 켜지기 전에 버튼을 누른 경우
* 켜진 LED와 다른 버튼을 누른 경우
* 여러 버튼을 동시에 누른 경우
* 제한시간 안에 버튼을 누르지 못한 경우

게임 오버 시 LCD와 UART에 실패 원인이 표시되고 게임 종료 음악이 재생됩니다.

<a id="5-lcd-기억력-게임"></a>

### LCD 기억력 게임

#### 5.1 게임 설명

LCD에 순서대로 표시되는 L·M·R 수열을 기억하고, 같은 순서로 버튼을 입력하는 게임입니다. 정답이면 기존 수열 뒤에 한 항목을 추가하며 최대 16단계까지 진행합니다.

#### 5.2 게임 진행 순서

1. USER 버튼으로 시작하면 LCD에 현재 단계가 표시됩니다.
2. L·M·R을 한 글자씩 600 ms 표시하고 250 ms 간격으로 지웁니다.
3. 수열 표시가 끝나면 버튼으로 같은 순서를 입력합니다.
4. 입력마다 LCD 위 줄에 해당 위치의 정답, 아래 줄에 입력값을 표시합니다.
5. 정답이면 다음 단계로 진행합니다.
6. 오답·동시 입력이면 실패하며 USER 버튼으로 1단계부터 다시 시작합니다.
7. 16단계를 완료하면 RESET으로 메뉴에 복귀합니다.

#### 5.3 입력 방법

| LCD 문자 | 대응 버튼 |
|---|---|
| L | BTN1 · 왼쪽 |
| M | BTN2 · 가운데 |
| R | BTN3 · 오른쪽 |

버튼 해제 후 다음 입력을 받으므로 길게 누른 입력을 여러 번 처리하지 않습니다.

#### 5.4 실패 조건

- 수열과 다른 버튼 입력
- 여러 버튼 동시 입력

기억력 게임에는 입력 제한시간을 두지 않았습니다. 제한시간 판정은 반응속도 게임에 적용합니다.

<a id="6-lcd-표시-내용"></a>

### LCD 표시

LCD는 현재 게임 상태를 사용자에게 알려주는 역할을 합니다.

표시되는 주요 내용은 다음과 같습니다.

* 게임 선택 메뉴
* 선택된 게임 이름
* 게임 시작 안내
* 현재 라운드
* 버튼 입력 대기
* 성공 또는 실패 여부
* 게임 클리어
* 게임 오버

예시:

```text
SELECT GAME
<REACT  MEMORY>
```

```text
REACTION GAME
ROUND 01 / 10
```

```text
LEVEL 1 / 16
WATCH...
```

```text
GAME OVER
TRY AGAIN
```

### 부저 출력

부저는 게임 상태를 소리로 알려주는 역할을 합니다.

| 상황         | 부저 기능            |
| ---------- | ---------------- |
| 게임 선택      | 선택 효과음 재생        |
| 반응속도 게임 시작 | 반응속도 게임 시작 음악 재생 |
| 기억력 게임 시작  | 기억력 게임 시작 음악 재생  |
| 라운드 성공     | 성공 효과음 재생        |
| 잘못된 버튼 입력  | 실패 효과음 재생        |
| 게임 클리어     | 클리어 음악 재생        |
| 게임 오버      | 게임 오버 음악 재생      |

게임 선택 음악과 각 게임 시작 음악은 서로 다르게 구성하여 현재 상태를 소리로도 구분할 수 있도록 하였습니다.

<a id="8-uart-터미널-출력"></a>

### UART 상태 출력

UART 터미널에서는 게임 진행 상황과 디버깅 정보를 확인할 수 있습니다.

통신 설정은 다음과 같습니다.

| 설정           | 값      |
| ------------ | ------ |
| Baud Rate    | 115200 |
| Data Bit     | 8 bit  |
| Parity       | None   |
| Stop Bit     | 1 bit  |
| Flow Control | None   |

반응속도 게임 출력 예시는 다음과 같습니다.

```text
==============================
 LED REACTION GAME - 10 ROUND
 BTN1->LED3, BTN2->LED2, BTN3->LED1
 Limit: 1000ms -> 550ms
==============================

[ROUND 1/10] LIMIT = 1000 ms
WAIT... do not press early
GO! LED3 ON
```

정상 입력 시:

```text
CORRECT!
REACTION TIME = 425 ms
```

시간이 초과된 경우:

```text
TIME OUT! LIMIT = 1000 ms
GAME OVER at round 1
```

<a id="9-프로젝트-실행-방법"></a>

### 빌드·다운로드

#### 9.1 하드웨어 연결

1. NUCLEO-F411RE 보드를 USB 케이블로 PC에 연결합니다.
2. LED, 버튼, LCD, 부저가 확장보드와 정상적으로 연결되어 있는지 확인합니다.
3. 보드에 전원이 정상적으로 공급되는지 확인합니다.

#### 9.2 터미널 설정

1. Tera Term을 실행합니다.
2. NUCLEO 보드의 ST-LINK Virtual COM Port를 선택합니다.
3. Baud Rate를 `115200`으로 설정합니다.
4. Data Bit는 `8`, Parity는 `None`, Stop Bit는 `1`로 설정합니다.

#### 9.3 컴파일

프로젝트 폴더에서 터미널을 실행한 후 다음 명령어를 입력합니다.

```bash
make clean
make all
```

#### 9.4 보드 다운로드 및 실행

컴파일이 완료되면 다음 명령어를 입력합니다.

```bash
make run
```

컴파일과 다운로드를 한 번에 실행하려면 다음 명령어를 사용할 수 있습니다.

```bash
make all run
```

다운로드가 완료되면 보드가 리셋되고 프로그램이 시작됩니다.

<a id="14-문제-해결"></a>

### 실행 문제 점검

#### 14.1 UART 터미널에 문자가 출력되지 않는 경우

* Tera Term의 COM Port가 올바른지 확인합니다.
* Baud Rate가 `115200`인지 확인합니다.
* 보드의 RESET 버튼을 누릅니다.
* USB 케이블을 다시 연결합니다.

#### 14.2 버튼이 계속 입력되는 경우

버튼을 계속 누르고 있으면 반복 입력이 발생할 수 있습니다.

프로그램에서 버튼이 해제될 때까지 기다리는 기능이 정상적으로 호출되는지 확인합니다.

```c
Button_Wait_All_Released();
```

#### 14.3 LED와 버튼 대응이 다른 경우

반응속도 게임의 대응 관계는 다음과 같습니다.

```text
BTN1 -> LED3
BTN2 -> LED2
BTN3 -> LED1
```

배선과 프로그램의 핀 설정이 동일한지 확인합니다.

#### 14.4 첫 라운드부터 시간 초과가 발생하는 경우

* 버튼 입력 함수가 실제 버튼 핀을 올바르게 읽는지 확인합니다.
* 버튼이 Active Low인지 확인합니다.
* 타이머가 정상적으로 시작되었는지 확인합니다.
* LED가 켜진 후 타이머 측정이 시작되는지 확인합니다.
* 버튼이 눌리기 전에 타이머가 종료되지 않는지 확인합니다.

<a id="13-주의사항"></a>

### 실행 조건

* 여러 버튼을 동시에 누르면 정상 입력으로 처리되지 않을 수 있습니다.
* 반응속도 게임에서 LED가 켜지기 전에 버튼을 누르면 실패 처리됩니다.
* 게임 시작 전에 이전에 눌려 있던 버튼을 모두 놓아야 합니다.
* LCD나 UART 출력이 보이지 않으면 보드의 RESET 버튼을 누릅니다.
* Tera Term의 Baud Rate가 `115200`인지 확인합니다.
* 다운로드가 되지 않으면 USB 연결과 ST-LINK 인식 상태를 확인합니다.
* 프로그램 실행 중 하드웨어 배선을 변경하지 않습니다.

<a id="16-프로젝트-실행-요약"></a>

### 실행 순서

```text
1. NUCLEO 보드를 PC에 연결한다.
2. Tera Term을 115200 Baud Rate로 실행한다.
3. 프로젝트 폴더에서 make all run을 입력한다.
4. BTN1으로 반응속도, BTN3으로 기억력 게임을 선택한다.
5. USER 버튼을 눌러 시작한다.
6. LCD와 LED의 안내에 따라 게임을 진행한다.
7. 게임 종료 후 RESET으로 메뉴에 복귀한다.
```
